# 原作者代码风格（改动前必读）

**核心原则：原作者已有的写法就是基准，新增/改动代码要模仿它。**
不要按外部规范去"修正"——本项目风格**有意偏离**通行规范。

复现：`python tools/audit_probes.py --only style_report`
（**复核口径**：git 已跟踪的 `.py`，排除 `tools/probes/`；下同）

> 数字会随改动变化，**以探针实测为准**，下表为 2026-09-23 快照。

| 文件头 | Founded / @author | **不加** |

## 四、命名与结构

| 项 | 本项目 |
|---|---|
| 单字母变量 | 允许（`i` / `d` / `k` 等 71 处）|
| 变量名 ≤20 字符 | ✅ 符合 |
| 目录结构 | **无 `src/`、无 `config/`**；见下 |

```
app/
├── main.py / first_run.py / diag_startup.py    入口与自检
├── core/        核心逻辑
│   └── engines/ 引擎实现 + registry 注册表
└── ui/          界面 + glass.py 设计系统
installer/       安装器
tools/           测试与辅助脚本
```

**值得保持的架构**：
`registry.py`（`@register` 注册表 + 插件）、`catalog.py`（清单与实现解耦，**改清单即可换模型**）、
`manager.py`（多层清单合并）、`glass.py`（统一设计令牌）。
